# Práctica 2.2 — Agrupación Jerárquica (Agglomerative Hierarchical Clustering)

Implementación en Python de clustering jerárquico aglomerativo con distancia euclidiana y enlace **Ward** sobre datos escalados (`StandardScaler`), incluyendo evaluación mediante coeficiente de silueta, distribución de elementos por clúster y visualización de dendrograma.

## Resultados de referencia (ejemplo con 150 muestras en 3 grupos)
- **Clústeres asignados:** `3`
- **Métrica / Enlace:** Euclidiana / `ward`
- **Coeficiente de silueta:** `0.8306`
- **Distribución por clúster:** `[50, 50, 50]`
